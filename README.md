# Power BI Sales Analysis Dashboard

## Overview

An interactive Power BI dashboard designed to analyze sales performance, revenue, profitability, and key business trends.

This project demonstrates practical Power BI skills including data modeling, DAX, interactive visualizations, dashboard design and Dataflow Gen2 in Microsoft Fabric.

## Key Features

* Executive KPI overview
* Revenue and profit analysis
* Sales performance trends
* Customer and product analysis
* Interactive slicers and filtering
* Drill-down and interactive report navigation
* Dynamic time-based analysis
* KPI and performance indicators
* Modern, recruiter-friendly dashboard design

## Power BI Skills Demonstrated

* Power BI Desktop
* Power Query
* Data Modeling
* Star Schema concepts
* DAX Measures
* Time Intelligence
* KPI Development
* Interactive Visualizations
* Slicers and Filters
* Drill-down Analysis
* Report Navigation
* Dashboard UX/UI Design

## Project Files

* Power BI report (`.pbix`)
* Supporting dataset/source files, where applicable
* Dashboard screenshots

## Purpose

This project was created as part of a Power BI portfolio to demonstrate the ability to transform business data into an interactive analytical report and communicate insights through effective dashboard design.

## Disclaimer

This project is intended for portfolio and educational purposes. The data and business scenario are used for demonstration and do not represent confidential company information.
